# Rapport Internship - Backend Case Study  

## 📖 Overview  
This repository contains a detailed case study of my internship at **Rapport (Stratawiz Technologies)**. It focuses on my backend development contributions in rapport for module **WhatsApp-based customer engagement platform**, similar to Interakt, built with **Node.js, Express.js, AWS, and DynamoDB**.  

## 🛠️ Technologies Used  
- **Backend:** Node.js, Express.js  
- **Database:** AWS DynamoDB  
- **Cloud Services:** AWS Lambda, Serverless Framework  
- **Third-party APIs:** WhatsApp API for messaging
